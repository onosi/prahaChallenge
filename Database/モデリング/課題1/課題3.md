## DDL作成
    
    ```sql
    CREATE TABLE "order" (
    	id serial PRIMARY KEY,
    	name varchar(100),
    	phone_number varchar(12),
    	isPaid boolean,
    	isTakeOut boolean,
    	requests text
    );
    
    CREATE TABLE set_menu_category(
    	id serial PRIMARY KEY,
    	name varchar(100)
    );
    
    CREATE TABLE set_menu(
    	id serial PRIMARY KEY,
    	"order" integer,
      category_id integer,
    	FOREIGN KEY (category_id) references set_menu_category(id)
    );
    
    CREATE TABLE menu(
    	id serial PRIMARY KEY,
      name varchar(100),
    	price integer,
    	set_menu_id integer,
    	FOREIGN KEY (set_menu_id) references set_menu(id)
    );
    
    CREATE TABLE order_detail(
    	order_id integer,
    	menu_id integer,
    	count integer,
    	excludesWasabi boolean,
    	primary key (order_id, menu_id),
    	FOREIGN KEY (order_id) references "order"(id),
    	FOREIGN KEY (menu_id) references menu(id)
    );
    
    CREATE TABLE ingredient(
    	id serial primary key,
    	name varchar(100)
    );
    
    CREATE TABLE menu_ingredient (
      menu_id integer,
      ingredient_id integer,
    	FOREIGN KEY (menu_id) references menu(id),
    	FOREIGN KEY (ingredient_id) references ingredient(id)
    );
    
    ```
    
    ```sql
    確認コマンド

    \d テーブル名;
    ```

##  ユースケースを想定したクエリ
- 特定のorderに紐づく、メニュー名と注文個数を一覧で表示する
    
    ```sql
    select menu.name AS "メニュー名" ,order_detail.count AS "個数" from 
        order_detail 
        left join menu on order_detail.menu_id = menu.id 
    where order_detail.order_id = 7;
    ```
- 特定の材料に紐づくメニューを取得する
    
    ```sql
    select * from menu where menu.id = (select menu_id from menu_ingredient where menu_ingredient.ingredient_id = 11);
    ``` 
- 100円のメニューを求める
    
    ```sql
    select * from menu where price = 100;
    ```
- セットメニューを一覧で表示する
    
    ```sql
    select menu.name AS "名前", menu.price AS "価格", set_menu_category.name AS "カテゴリー名" from menu 
    left join set_menu on menu.set_menu_id = set_menu.id 
    left join set_menu_category on set_menu_category.id = set_menu.category_id 
    where menu.set_menu_id is not null;
    ```
- セットメニュー以外を一覧で表示する
    
    ```sql
    select * from menu
    where menu.set_menu_id is null;
    ```
