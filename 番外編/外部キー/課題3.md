# 課題3

## クイズ

第1問：基本編
外部キー制約の目的として正しいものはどれか？

A. データの重複を防ぐため
B. データベースのサイズを小さくするため
C. 関連するテーブル間のデータ整合性を保つため
D. トリガーを自動的に作成するため

正解：C
解説： 外部キー制約は、親子テーブル間のリレーションにおけるデータ整合性を確保するために使われます。たとえば、存在しないユーザーにコメントを紐づけることなどを防ぎます。

第2問：応用編（MySQL vs PostgreSQL）
MySQLとPostgreSQLのRESTRICTとNO ACTIONの動作に関して正しい説明はどれか？

A. MySQLではNO ACTIONとRESTRICTは同じ動作になる
B. PostgreSQLではRESTRICTがトランザクション終了時に制約を評価する
C. MySQLはNO ACTIONをサポートしていない
D. PostgreSQLではNO ACTIONは常に即時制約である

正解：A
解説： MySQLではNO ACTIONとRESTRICTの違いがなく、どちらも即座に外部キー制約を評価します。一方、PostgreSQLではNO ACTIONがトランザクション遅延評価に対応する場合があります。

第3問：設計判断編
次のうち、ON DELETE SET NULL の利用に適しているケースはどれか？

A. 削除された親レコードと関連する子レコードもすべて削除したい場合
B. 子レコードの参照が必須で、親が削除されることは許されない場合
C. 子レコードを残しつつ、親が削除されたときに参照を無効にしたい場合
D. 親と子のレコードは常に1対1で存在すべき場合

正解：C
解説： ON DELETE SET NULL は、親レコードが削除されたときに、子レコードの外部キーをNULLにして関連を切る設定です。たとえば、担当者が削除されたときに、その案件の担当者情報を「未定」にしたいケースなどに使われます。
