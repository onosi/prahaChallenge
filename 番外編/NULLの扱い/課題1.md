# 課題1 
SQLクエリで以下の式を実行した時の結果を答えてください。

## SELECT NULL = 0

* 結果: NULL
* 理由: 
    * NULLが未知の状態のため、NULLと0が等しいかは不明(unknown)
    * 評価結果がunknownの場合、SQLではNULLが返却されるため、NULLと評価される

## NULL = NULL 

* 結果: NULL
* 理由: NULL 同士の比較でも、どちらも「不明」なため、等しいと判断できない。比較の結果は UNKNOWN → NULL。

## NULL <> NULL

* 結果: NULL
* 理由: 「NULL は NULL と違うか？」も不明なので、結果は UNKNOWN → NULL。

## NULL AND TRUE

* 結果: NULL
* 理由:ANDの場合、評価優先度は false ＞ unknown(null) ＞ trueの順となる。よって、UNKNOWN → NULL

## NULL AND FALSE

* 結果: FALSE
* 理由: ANDの場合、評価優先度は false ＞ unknown(null) ＞ trueの順となる。よって、FALSE

## NULL OR TRUE

* 結果: TRUE
* 理由: ORの場合、評価優先度はtrue ＞ unknown(null)  ＞ false。よって全体は TRUE

## NULL IS NULL

* 結果: TRUE
* 理由: IS NULL は NULL 判定専用演算子で、NULL であるかを明確に判断できる。

## NULL IS NOT NULL

* 結果: FALSE
* 理由: NULL は確かに NULL である → 「NULL ではないか？」には FALSE と答える。
