# 課題4 - NULLの扱いに関するクイズ

## 第1問：NULLと比較演算（課題1関連）

次のSQLクエリの実行結果として正しいものはどれか？

```sql
SELECT * FROM employees WHERE salary <> 50000;
```

employeesテーブルには以下のデータが入っている：

| id | name  | salary |
|----|-------|--------|
| 1  | Alice | 60000  |
| 2  | Bob   | NULL   |
| 3  | Carol | 50000  |

**選択肢：**
- A. Alice と Bob が返る
- B. Alice のみ返る  
- C. Alice と Carol が返る
- D. すべてのレコードが返る

**正解：B. Alice のみ返る**

**解説：**
課題1で学習した通り、NULLとの比較演算（`<>`）はUNKNOWN（NULL）となる。WHERE句ではTRUEのレコードのみが抽出されるため、Bobの行は除外される。Carol（salary = 50000）も条件（`<> 50000`）に該当しないため除外される。

## 第2問：NULLと集約関数（課題2関連）

課題2では、Issueテーブルのassignee_idにNULLが含まれる問題を扱った。次のSQLの実行結果はどうなるか？

```sql
SELECT COUNT(*), COUNT(assignee_id), AVG(assignee_id) FROM issues;
```

issuesテーブル：

| id | title      | assignee_id |
|----|------------|-------------|
| 1  | Bug修正    | 101         |
| 2  | 機能追加   | NULL        |
| 3  | テスト     | 102         |
| 4  | リファクタ | NULL        |

**選択肢：**
- A. COUNT(*) = 4, COUNT(assignee_id) = 4, AVG(assignee_id) = 67.75
- B. COUNT(*) = 4, COUNT(assignee_id) = 2, AVG(assignee_id) = 101.5
- C. COUNT(*) = 2, COUNT(assignee_id) = 2, AVG(assignee_id) = 101.5
- D. エラーになる

**正解：B. COUNT(*) = 4, COUNT(assignee_id) = 2, AVG(assignee_id) = 101.5**

**解説：**
- `COUNT(*)` は全行をカウントするため4
- `COUNT(assignee_id)` はNULLを除外して非NULLの値のみをカウントするため2
- `AVG(assignee_id)` もNULLを除外して計算するため (101 + 102) / 2 = 101.5

これが課題2で検討した「担当者がNULLの場合に統計が歪む問題」の典型例である。

## 第3問：NULLの判定方法（課題1関連）

課題1で学習したNULLの基本的な扱い方に関する問題。次のSQL文のうち、due_dateがNULLであるタスクを正しく抽出できるものはどれか？

```sql
-- A
SELECT * FROM tasks WHERE due_date = NULL;

-- B  
SELECT * FROM tasks WHERE due_date IS NULL;

-- C
SELECT * FROM tasks WHERE due_date != NULL;

-- D
SELECT * FROM tasks WHERE due_date IS NOT NULL;
```

**選択肢：**
- A. Aのみ
- B. Bのみ
- C. BとD
- D. AとC

**正解：B. Bのみ**

**解説：**
課題1で学習した通り：
- `= NULL` や `!= NULL` は常にUNKNOWN（NULL）となり、WHERE句で除外される
- NULLの判定には `IS NULL` を使用する必要がある
- `IS NOT NULL` はNULLでない値を抽出する（今回の問題とは逆）

## 第4問：設計判断（課題2・課題3関連）

課題2では中間テーブルを使ってNULLを避ける設計を提案し、課題3では「真にNULLという値を入れるべきケース」について議論した。

次のケースで、NULLを使用することが適切なのはどれか？

**選択肢：**
- A. ユーザーのログインID（必須項目）
- B. 商品の製造終了日（製造中の商品は未定）
- C. 注文の合計金額（必須項目）
- D. ユーザーの作成日時（必須項目）

**正解：B. 商品の製造終了日（製造中の商品は未定）**

**解説：**
課題3で学習した通り、NULLは「値が存在しない・未設定・不明」という状態を表す。製造終了日の場合：
- 製造中の商品：製造終了日は「未定」なのでNULLが適切
- 製造終了済みの商品：実際の終了日を設定

デフォルト値（例：9999-12-31）を設定すると、「製造終了日が9999年12月31日」という誤解を招く可能性がある。このケースでは、NULLが業務的な意味を正確に表現できる。

## 第5問：総合問題（課題1・2・3統合）

以下のクエリを実行した場合の結果を予測せよ ：

```sql
SELECT 
    COUNT(*) as total_issues,
    COUNT(assignee_id) as assigned_issues,
    COUNT(CASE WHEN assignee_id IS NOT NULL THEN 1 END) as assigned_issues_v2
FROM issues 
WHERE status != 'closed' OR status IS NULL;
```

issuesテーブル：

| id | title    | assignee_id | status   |
|----|----------|-------------|----------|
| 1  | Bug修正  | 101         | open     |
| 2  | 機能追加 | NULL        | NULL     |
| 3  | テスト   | 102         | closed   |
| 4  | 調査     | NULL        | open     |

**正解：total_issues = 3, assigned_issues = 1, assigned_issues_v2 = 1**

**解説：**
1. WHERE句の評価：
   - id=1: 'open' != 'closed' → TRUE
   - id=2: NULL != 'closed' → UNKNOWN, NULL IS NULL → TRUE → 全体TRUE（OR結合）
   - id=3: 'closed' != 'closed' → FALSE, 'closed' IS NULL → FALSE → 全体FALSE
   - id=4: 'open' != 'closed' → TRUE

2. 結果として id=1,2,4 の3行が抽出される

3. 集約関数の結果：
   - `COUNT(*)`: 3行すべてをカウント → 3
   - `COUNT(assignee_id)`: NULLを除外して101のみカウント → 1  
   - `COUNT(CASE...)`: 同様にNULLでない値のみカウント → 1

この問題は課題1（NULLとの比較）、課題2（集約関数でのNULL除外）、課題3（NULLの意味）すべての知識を統合した実践的な例である。
